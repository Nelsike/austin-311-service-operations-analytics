**Project name:** Austin 311 Service Operations Analytics

**Date:** November 2026

**Project type:** Personal portfolio project. Do not associate it with paid City employment.

**Description:**

Analyzed 73,690 Austin Transportation and Public Works 311 requests created in 2025 using Python, SQL and Power BI. Built a reproducible cleaning pipeline, SQLite analytical database and three-page Power BI report covering request demand, administrative closure times, recorded deadlines and reported open records.

Documented duplicate-marked reports, conflicting status flags and ambiguous daylight-saving timestamps. Validated Power BI results against Python and SQL, and developed evidence-based recommendations for status reconciliation and service-specific operational review. Distinguished administrative closure from independently verified resolution throughout the analysis.

Personal portfolio project using official City of Austin open data.

**Skills:** SQL; Python; Microsoft Power BI; Data Cleaning; Data Visualization.
